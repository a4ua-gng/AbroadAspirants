# Abroad Aspirants

A student-led study-abroad community from India. This is an updated build which aims to rectify, minimalise and simplify most of the code.

## Preview

Open `index.html` in a modern browser, or serve the repository root with `python3 -m http.server 8000` and open `http://localhost:8000`.

## Editing

- `index.html` contains the page structure, community links and team.
- `styles.css` contains the visual theme. 
- `app.js` contains the entire rendering logic
